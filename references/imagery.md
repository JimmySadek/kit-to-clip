# Imagery only where the story needs it

Skip this route for a graphics-only treatment. Establish the scene's need before searching: subject, purpose,
style, framing, image box, aspect ratio and largest crop/zoom. Reuse supplied assets and the chosen brand kit first.
Do not turn a missing picture into a mandatory generation task or search unrelated private collections.

## Choose the smallest useful route

- **Existing image:** inspect the actual file and available original, not just a thumbnail. Keep real products,
  interfaces, logos and factual imagery accurate. Record its source and intended scene.
- **Free high-resolution image:** use available web/image search to find a suitable original from a source that
  states reuse terms. Open the image's source page and check resolution, permitted use and attribution. Free
  access alone does not establish commercial reuse permission. Record the exact source and licence evidence.
- **Generated image:** offer a host-supported model, such as Codex image generation, or a guided handoff to an
  available service such as Gemini Nano Banana. Verify actual tool access. Explain any account/credit requirement
  and which prompt or supplied assets would leave the local project. Obtain that route's choice before sending
  them. Do not silently upload private material or install another provider.

Prepare the generation prompt for the person or the authorised tool: scene purpose, subject, medium matching the
chosen style, composition/negative space, lighting, palette roles, aspect ratio and required pixels. Identify
which supplied elements must remain exact. A guidance file or a link is not a generated asset; get the actual
returned file before building with it. Use the host's image-generation skill/tool when available, including its
rules for inspecting edits and saving output.

## Check the asset at its largest use

Use actual pixel dimensions. Allow for the portion discarded by cropping and the largest enlargement in motion.
For example, a 1080-pixel-wide image box with 1.4x zoom and only 60% of the image width retained needs at least
2520 source pixels across (1080 × 1.4 ÷ 0.6). Check height separately. This is a resolution calculation, not a
guarantee of photographic quality. Inspect the crop, artefacts, lettering and recognisable subjects yourself.

Keep approved files under this video's project assets. In `film.json` `inputs`, record the path, a `kind` and a
`note` with the creative role and crop/zoom intent, the original/source page, licence/attribution evidence,
pixel dimensions, or the generation prompt/model/settings and any permitted-use limits. Retain original files;
make crop/edit derivatives separately. Never put private job images into the public skill package.

The chosen asset reaches the fresh builder through these files and brief inputs. A changed file makes dependent
approvals stale. Pure provenance updates do not change the approved picture. Voice and image preparation can overlap
after shared creative inputs are stable, with one coordinator maintaining the brief.
